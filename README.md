# تعديل المستندات

موقع بسيط لتوقيع ملفات PDF وختمها: ارفع المستند، ارسم توقيعك، ضع التوقيع والختم في مكانهما، ثم نزّل الملف الموقّع.

- تتم كل المعالجة داخل المتصفح، ولا يُرفع أي مستند إلى أي خادم.
- يعمل على الكمبيوتر والجوال.
- للتشغيل المحلي دون إنترنت: شغّل `start.bat` أو افتح `index.html`.

يعتمد على PDF.js (للمعاينة) و pdf-lib (لتعديل الملف وتصديره).
